The running application exposes `/about`, linked from its ordinary interactive interfaces, with the version, copyright, license and upstream source repository. Distributors of modified network versions must update that source offer when the upstream repository is no longer the corresponding source for their deployment.

AGPL-3.0 permits running, studying, modifying and redistributing the program, including commercial activity. Its strong copyleft requires covered derivative works to remain under the same license when conveyed. Section 13 also requires an operator of a modified network version to offer its corresponding source to users interacting with it remotely.

Practical examples:

- a consultant may charge for installation, customization and support;
- a vendor may sell an appliance containing Turnino, while satisfying the source and installation-information obligations that apply;
- a hosting provider may sell access to the service;
- if that provider runs a modified Turnino, its remote users must be offered the corresponding source of that version;
- merely using an unmodified public release does not create a requirement to publish unrelated business data or configuration secrets.

The application UI must eventually include a visible source-code link so deployments and downstream modifications can satisfy the network-use provision cleanly.

Third-party assets and dependencies retain their own licenses. This document is a practical summary, not legal advice.
