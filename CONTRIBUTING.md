# Contributing

Turnino is not open for general contributions yet, but early design feedback is welcome.

## Development workflow

1. Create a focused branch from `main`.
2. Run `make check` before opening a pull request.
3. Keep changes small and preserve the KISS principles in the README.
4. Add or update tests for changed behavior.
5. Document user-visible configuration and migrations.

Use Conventional Commit-style subjects where practical, for example `feat: add counter registration` or `fix: serialize number allocation`.

Do not include production data, credentials, session identifiers, personal data, or database exports.
